# 化学方程式配平与守恒核对工作台

基于 Vue 3 + TypeScript + Vite 的教学工具，帮助学生理解配平系数如何同时满足**元素守恒**与**电荷守恒**。全部解析与求解在浏览器本地完成，使用 BigInt 与精确有理数运算，不做浮点近似。

## 启动方式

```bash
npm install          # 首次（仓库已附带 node_modules 时可跳过）
npm run dev          # 开发服务器，默认 http://127.0.0.1:5173/
npm test             # 运行 Vitest 测试（解析器 / 求解器 / 组件）
npm run build        # 类型检查 + 生产构建（输出到 dist/）
npm run preview      # 预览生产构建
```

## 输入语法

每种物质单独占一行，左右两栏分别为反应物和生成物。

- **元素与下标**：元素符号首字母大写（`Fe`、`Cl`），下标为正整数，如 `H2O`、`C6H12O6`。
- **分组括号**：支持多层 `( )`（也兼容 `[ ]`、`{ }`），括号外下标乘整个分组：`Ca(OH)2`、`Ca3(Fe(CN)6)2`。
- **结晶水**：用 `·`（或 ASCII `.`）分隔，点号后整数只乘该一段：`CuSO4·5H2O` 计为 Cu×1、S×1、O×9、H×10。
- **电荷**：写在整个化学式末尾，形如 `Mg^2+`、`SO4^2-`、`H^+`、`Cl^-`。
- **电子**：固定写作 `e^-`，带 1 个单位负电荷、不含任何元素。

解析错误（未知元素、空分组、下标为 0、括号不匹配、电荷位置非法等）会直接标红出错的那一行，并给出字符位置。

## 核心操作

- 每栏可添加、删除、上移/下移物质行；顺序即方程式中的展示顺序。
- **键盘操作**：输入框内 `Enter` 跳到下一行（末行自动新增）；空行按 `Backspace` 删除；`Alt+B` 全局触发配平。
- 点击「配平」后：
  - 有唯一最简正整数解时，展示易读方程式（系数 gcd 为 1）与守恒核对表（逐元素 + 电荷，列出左右总数）。
  - **无解**（只有零解）、**必须出现零/负系数**、**解空间多于一维**三种情况会分别说明原因，不会任选一组解冒充唯一答案。
- 点击核对表中的元素名，可在全部物质中突出该元素的单份含量（系数 × 含量即表中总数），便于追查嵌套分组与结晶水计数。
- 输入一旦修改或出现解析错误，旧结果立即显示失效横幅，不能继续复制为当前答案；重新配平后恢复。
- 「复制纯文本方程式」把结果复制为形如 `2H2 + O2 → 2H2O` 的纯文本。

页面内置四组示例：普通燃烧反应、多层嵌套分组、结晶水脱水、含电子的离子半反应（高锰酸根还原）。

## 限量试剂与投料方案

配平得到**唯一全正系数**后，下方出现「限量试剂与投料方案」区（含电子 `e^-` 的半反应会提示不适用）。

- **投料录入**：每种反应物填写非负数量，单位支持 `mol`、`mmol`、`g`；每种物质可填正摩尔质量（g/mol）。按 g 投料必须填写该物质摩尔质量；未填摩尔质量的生成物只显示物质的量产量。只接受普通十进制数，空值、负数、非法文本会在对应字段下方定位提示，**不会被当作 0**。
- **计算假设**：反应完全进行且无副反应。将投料统一换算为 mol 后，以各反应物 `n / 系数` 的最小值作为反应进度 ξ，取到最小值的全部反应物列为**并列限量试剂**；据此给出各反应物消耗量/剩余量与各生成物理论产量，质量按各自摩尔质量计算。
- **精确度**：内部全程使用 BigInt 精确有理数比较与运算，仅在显示时保留 6 位有效数字，`≈` 表示经舍入；并列限量与零剩余由精确值判定，不会因近似制造并列或负剩余。
- **方案管理**：可新建、命名、复制、切换、删除多个投料方案；复制后独立编辑，数量、单位、摩尔质量互不影响。编辑任一投料字段会使该方案结果失效；结果有效的方案会在下方并排对比限量试剂与各生成物产量。
- **联动失效**：物质调序时投料随对应物质移动；增删物质或修改化学式后，所有方案结果失效，需重新配平并核对输入后再计算。
- **投料示例**：提供「恰好配比」（各反应物 = 系数 mol，全部并列限量）与「试剂过量」（第一种反应物加倍）两个一键示例。

## 多步反应流程

在单反应配平 + 投料的基础上，页面底部「多步反应流程」区支持把多个反应串成流程，追踪中间产物的分流与合流。

- **保存步骤**：当前反应配平出唯一全正解且不含电子 `e^-` 后，点击「保存当前反应为流程步骤」，把方程式与系数存为独立快照。步骤可命名、编辑补料、删除、上下调序；上方工作台的后续修改不影响已保存步骤。
- **外部补料**：每个步骤的反应物可填外部补料，沿用单反应的 `mol` / `mmol` / `g` 与摩尔质量校验；允许填 0，留空视为不补料。
- **流程连接**：从某步的生成物连到另一步的反应物，只允许去掉空白后化学式相同的物质。每条连接填 `(0, 100]` 的十进制百分比，表示分配该生成物总产量的比例；同一生成物各连接比例之和不得超过 100%，未分配部分留存。自连、重复连接、循环依赖会被拒绝并定位到具体步骤或连接；删除步骤会同时移除其关联连接。
- **计算规则**：按依赖顺序（拓扑序）逐步计算。每个反应物的可用量 = 外部补料 + 全部上游送入（支持多来源合流，已分配的产物不会被重复使用），再按与单反应相同的精确限量规则（ξ = min n/系数）求消耗、剩余与产量。剩余反应物不自动转送。步骤调序只改变展示顺序，不影响结果与物质绑定。
- **物料账**：校验全部通过后才发布完整结果；列出每步的补料、各来源送入、可用、消耗、剩余、产量、已转送（含去向与比例）与留存量。编辑步骤、补料或连接后整套旧结果立即失效，需重新点击「计算全流程」，不会混用新旧结果。
- **示例**：点击「载入多步示例（分流 + 合流）」生成三步流程——蒸汽重整（CH4 + H2O → CO + 3H2）、甲醇合成（CO + 2H2 → CH3OH）、电解水（2H2O → 2H2 + O2）；蒸汽重整的 CO 全部、H2 的 50% 送入甲醇合成，电解水的 H2 全部合流进甲醇合成。假设每步完全反应且无副反应。

## 求解原理

1. 解析器将每个物质展开为「元素 → 原子数」的整数计数与净电荷。
2. 以物质为列、元素与电荷为行建立齐次线性方程组（反应物取正、生成物取负）。
3. 用 BigInt 分子/分母的分数做高斯-若尔当消元，求零空间基：
   - 零空间为 0 维 → 无解；多于 1 维 → 解不唯一；
   - 1 维时把基向量通分取整、约去最大公约数，再检查是否全部为正。

## 目录结构

- `src/lib/elements.ts`：118 个元素符号表
- `src/lib/parser.ts`：化学式解析器（括号 / 结晶水 / 电荷）
- `src/lib/fraction.ts`：精确有理数
- `src/lib/solver.ts`：守恒矩阵与零空间求解
- `src/lib/stoich.ts`：投料换算、限量试剂与理论产量（精确有理数）
- `src/App.vue`：两栏录入、结果展示、守恒核对与高亮
- `src/lib/__tests__/`：解析器、求解器与组件测试
